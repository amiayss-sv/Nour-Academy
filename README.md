# Nour Academy — Portail d’inscription

## Contexte du projet
Nour Academy est un réseau de trois centres de soutien scolaire
et de langues à Nador.

Ce projet permet aux parents de consulter les cours, de préparer
leur sélection et de remplir un dossier d’inscription depuis
leur téléphone.

Projet individuel réalisé dans le cadre de la formation YouCode.

## Règles de validation
- Les champs obligatoires doivent être renseignés.
- L’email doit respecter le format attendu.
- Le téléphone doit respecter le format marocain demandé.
- Le mot de passe doit contenir au moins 8 caractères,
  une majuscule, un chiffre et un caractère spécial.
- La confirmation doit correspondre au mot de passe.
- Au moins un cours doit être sélectionné.
- Le consentement doit être coché.

## Installation
1. Cloner le dépôt.
2. Ouvrir le dossier dans VS Code.
3. Ouvrir index.html dans le navigateur.
